# EUR/USD Signal Platform

Professional trading signal platform for EUR/USD with real-time analysis, technical indicators, and machine learning predictions.

## Features

- Real-time EUR/USD data from Yahoo Finance
- Comprehensive technical analysis (RSI, MACD, Bollinger Bands, ATR)
- Support and resistance level detection
- Automated signal generation with entry, stop loss, and take profit levels
- Risk management calculations
- WebSocket real-time updates
- RESTful API
- Web dashboard
